## Basic Configuration

To enable telemetry, configure your environment to export data via OTLP:

```bash
OTEL_METRICS_EXPORTER=otlp
OTEL_TRACES_EXPORTER=otlp
OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4317
OTEL_EXPORTER_OTLP_PROTOCOL=grpc
```

---

<Aside type="tip">
OpenTelemetry defaults to a 60-second export interval.
For faster feedback during testing, set `OTEL_METRIC_EXPORT_INTERVAL=1000` to
export metrics every second.
</Aside>

---

## Backlog stats

Backlog metrics (`pending_count` and `oldest_age_seconds`) require heavy database
queries. To prevent potential throughput impact, these are disabled by default.

Enable them by setting:

```bash
ENABLE_STATS=true
```

For a full list of available metrics and trace attributes, check the [Diagnostics Reference](/reference/diagnostics).
